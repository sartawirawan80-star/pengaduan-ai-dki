# AI Klasifikasi Pengaduan Masyarakat DKI Jakarta

Demo implementasi model Transformer (IndoBERT) untuk klasifikasi pengaduan masyarakat.

## Cara Menjalankan Lokal

pip install -r requirements.txt
streamlit run app.py

## Deploy Online

1. Upload ke GitHub
2. Buka https://streamlit.io/cloud
3. Hubungkan repo GitHub
4. Pilih app.py
5. Deploy

Aplikasi akan memiliki link publik.
